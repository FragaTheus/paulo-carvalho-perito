# Release 02 — Site comercial editorial

**Projeto:** Paulo Carvalho — Perito e Assistente Técnico Trabalhista
**Versão:** 02
**Commit:** `d26d3c7` — `feat: rebuild Paulo Carvalho commercial editorial site`

## Resumo

Reconstrução do site institucional como site comercial editorial, com conteúdo orientado à apresentação dos serviços profissionais, páginas dedicadas por público e área técnica, e base preparada para descoberta orgânica.

## Entregas

- Nova aplicação em Angular 21 com componentes standalone e rotas carregadas sob demanda.
- Renderização SSR e prerenderização das seis páginas públicas.
- Estilização responsiva usando Tailwind CSS 4.
- Páginas para início, advogados, empresas, insalubridade, periculosidade e acidente de trabalho.
- Componentes reutilizáveis para cabeçalho, menu, rodapé, FAQ, chamadas de contato, hero e cards.
- Metadados SEO por rota, canonical, Open Graph, Twitter Cards e dados estruturados JSON-LD.
- Arquivos `robots.txt` e `sitemap.xml`, além de favicon SVG com as iniciais PC.
- Imagens do hero e da seção Sobre convertidas para WebP e ajustadas para as dimensões do layout.
- Conteúdo editorial do site e documentação de auditoria, estratégia e implementação SEO.
- README técnico com arquitetura, estrutura, rotas e instruções para desenvolvimento, build e SSR.

## Validação

- `npm run build` concluído com sucesso.
- As seis rotas foram prerenderizadas.
- Metadados por página, canonical, um H1 por rota, JSON-LD, favicon e sitemap foram conferidos no build.
